01 / Featured system

CalEyeZ

Food recognition becomes more useful when a camera prediction can meet a measurement from the physical world.

Computer vision + sensor fusion

From a photograph
to an accountable result.

Co-developed with Roi Tzur. A camera image goes through a 132-class global expert and a 13-class Israeli-food expert. An XGBoost arbiter selects the route. A BLE scale supplies mass, which the application combines with a food reference to estimate nutrition.

The work was not only training models. It included the capture flow, routing, scale integration, interface and independent checks against real photos.

Architecture studies

Four other ways
to think in systems.

The projects below are deliberately shown as signal paths, not résumé bullets.

02Event systems / Python

Home camera system

An event pipeline built around real cameras and imperfect signals. Frigate provides detection and tracking; my Python logic consumes events, handles delay and duplication, records identity decisions and leaves an audit trail that can be checked against the footage.

Frigate is an integrated component, not a detector I wrote from scratch.

03Digital design / VLSI

MIPS processor

Instruction flow, datapath and control built as one digital system. A custom instruction-set extension explored how to reduce loop-execution cycles in the studied workload.

Read the MIPS project report ↗
04Analog IC design

CMOS operational amplifier

A transistor-level, two-stage amplifier study: design the signal path, stabilize it with compensation, then characterize the simulated behavior. This is simulation work, not a claim of fabricated silicon.

Read the CMOS design report ↗
05RTL / state machines

Verilog TX/RX

A transmitter and receiver modeled as coordinated finite-state machines. The emphasis is on timing, state transitions and the data path between them.
